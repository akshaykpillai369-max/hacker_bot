# HackerBot 🤖

A slack bot for hackers

## 🚀 Features

* **`/hacker_bot_ping`** - Check real-time bot latency.
* **`/hacker_bot-vuln`** - Fetch live vulnerability security alerts from NIST's NVD API.
* **`/hacker_bot-passcheck`** - Test password strength .
* **`/hacker_bot-catfact`** - Get a random cat fact.
* **`/hacker_bot-joke`** - Get a joke.
* **`/hacker_bot-help`** - View available commands
